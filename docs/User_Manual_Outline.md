# Mizan — User Manual Outline
**Version:** 1.0  
**Date:** 2026-05-01  
**Application:** Mizan Personal Finance Manager (ميزان)

---

## 1. Introduction

- What is Mizan? Overview of core features (projects, expenses, warranties, file vault, reports, sharing).
- Supported browsers and minimum requirements.
- Language and theme controls (Arabic / English, Light / Dark mode).

---

## 2. Registration

1. Navigate to the application URL.
2. Click **"إنشاء حساب"** (Create Account) on the Welcome page.
3. Fill in:
   - Full name
   - Email address
   - Password (minimum 6 characters; guidance on strong passwords)
4. Click **Register**.
5. Confirmation and automatic redirect to the dashboard on success.
6. Troubleshooting: email already in use, password too short.

---

## 3. Creating a Project

1. From the dashboard, click **"مشروع جديد"** (New Project).
2. Complete the project form:
   - **Name** (required) — e.g., "تجديد المنزل"
   - **Type** — choose an icon (car, house, occasion, work, devices, custom)
   - **Budget** (optional) — maximum planned spend in SAR
   - **Selling Price** (optional) — for profit/loss tracking
   - **Description** (optional)
   - **Colour** — accent colour for the project card
3. Click **Save**.
4. The new project appears as a card on the Projects page.
5. Project status lifecycle: Active → Done → Archived.

---

## 4. Adding Expenses

1. Open a project by clicking its card.
2. On the **Project Detail** page, click **"إضافة مصروف"** (Add Expense).
3. Fill in the expense form:
   - **Title** (required)
   - **Amount** in SAR (required, must be > 0)
   - **Category** — e.g., مواد، عمالة، خدمات
   - **Vendor** (optional)
   - **Purchase Date**
   - **Notes** (optional)
4. Click **Save**.
5. The expense appears in the list; budget and profit/loss figures update automatically.
6. Editing and deleting expenses: use the action icons on each row.
7. Attaching a warranty to an expense: click the shield icon → enter warranty end date.

---

## 5. Uploading Vault Files

1. On the Project Detail page, select the **"الملفات"** (Files) tab.
2. Click **"رفع ملف"** (Upload File) or drag-and-drop into the upload zone.
3. Supported file types: PDF, JPEG, PNG, WEBP, GIF, HEIC, DOCX, XLSX, ZIP, and others.
4. Maximum file size: **500 MB** per file.
5. The file appears in the vault list with size, date, and type badge.
6. Deleting a file: click the trash icon; confirm the prompt. The file is permanently removed.
7. Note: download links in the vault are private — accessible to the project owner only.

---

## 6. Exporting Reports

1. Navigate to **"التقارير"** (Reports) from the sidebar.
2. **Summary report**: displays total spend, budget usage, profit/loss, and warranty status across all projects.
3. **Export to Excel / CSV**: click the **Export** button; a file downloads to your device.
4. **Export project archive (ZIP)**: on the Project Detail page, click **"تصدير ZIP"**. The archive includes expense data and all vault files for that project.
5. **Activity log export** (admin only): available from the Admin panel → Logs.
6. Interpreting the budget bar: green (< 75%), amber (75–90%), red (> 90%).

---

## 7. Sharing a Project (Read-Only Link)

1. On the Project Detail page, click **"مشاركة"** (Share).
2. Click **"إنشاء رابط مشاركة"** — a unique 30-day link is generated.
3. Copy the link and share it with recipients.
4. Recipients can view expenses, file names, charts, and warranty status — but cannot edit anything.
5. To revoke the link: click **"إلغاء رابط المشاركة"**. The link becomes invalid immediately.
6. Only one active share link exists per project at a time; creating a new link revokes the previous one.

## 8. Account Settings
